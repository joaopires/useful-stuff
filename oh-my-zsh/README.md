# 🐚 Oh My Zsh Plugins

A collection of custom plugins for Zsh.

## Bare Clone Plugin (`/bare-clone`)

### `bare-clone.plugin.zsh`

A plugin providing the `git-bare-clone` function. It automates the setup of a bare repository with worktree support, including refspec configuration and upstream tracking.

#### Usage

To use the plugin, source it in your `.zshrc` or copy it to your custom Oh My Zsh plugins folder:

```bash
source path/to/useful-stuff/oh-my-zsh/bare-clone/bare-clone.plugin.zsh
```

Or symlink it:

```bash
ln -s path/to/useful-stuff/oh-my-zsh/bare-clone ~/.oh-my-zsh/custom/plugins/bare-clone
```
